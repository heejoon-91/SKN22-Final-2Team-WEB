## 6.2 Pet Profile

```json
{
  "pet_id": "uuid",
  "user_id": "uuid",
  "name": "string",
  "species": "cat | dog",
  "breed": "string | null",
  "gender": "male | female",
  "age_years": "int",
  "age_months": "int",
  "weight_kg": "float | null",
  "neutered": "true | false | null",
  "vaccination_date": "date | null",
  "health_concerns": ["skin", "joint", "digestion", "weight", "urinary", "eye", "hairball", "dental", "immunity"], # 개/고양이 건강정보가 혼합되어 있음. 분류하면 좋을 듯
  "allergies": ["string"],
  "food_type_preference": ["dry", "wet_can", "wet_pouch", "freeze_dried", "raw"],
  "budget_range": "under_10k | 10k_30k | 30k_50k | over_50k", # 기간/품목카테고리 선정이 되어 있지 않은 상태에서, 예산을 입력하는건 모호할 수 있음
  "used_product_ids": ["string"], # 기존에 사용했던 제품명을 단순 입력하는 것은 도움이 되지 않을 듯. 해당 제품의 정보를 알 수 없기 때문에.
  "special_notes": "string | null", -> llm이 동물정보로 인식하고 판단하려면 수의학적 정보의 finetuning이 필요할 것으로 보임.
  "created_at": "datetime",
  "updated_at": "datetime"
}
```

## 6.4 Product Card

```json
{
  "goods_id": "string", # 제품 번호
  "goods_name": "string", # 제품 명
  "brand_name": "string", # 브랜드 명
  "price": "int", # 가격
  "discount_price": "int", # 할인 가격
  "rating": "float", # 평점
  "review": "string", # 리뷰 내용
  "review_count": "int", # 리뷰 갯수
  "thumbnail_url": "string", # 제품 표지 사진
  // "product_url": "string", 제품 상세 페이지는 안 보여주기로
  "category_tags": ["string"], # 품목 카테고리 -> 제품 성분 정보가 들어가 있다면, 따로 제품 성분 정보는 column을 만드는게 좋을 듯
  "reason": "string", # ? 이유? 원인?
}
```
